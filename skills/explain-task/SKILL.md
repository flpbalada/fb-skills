name: explain-task
description: Explain the current state and requested change from the given context.
---

Read the given context and return two bullet points:

- Current state: Explain how it works now.
- Requested change: Explain what should change.

Use short sentences, simple words, and active voice inspired by ASD-STE100.
Preserve key conditions. Use only facts from the context.
Omit jargon, internal details, hype, and hashtags.
Default to English and stay within 280 characters unless requested otherwise.
Return only the two bullet points.
